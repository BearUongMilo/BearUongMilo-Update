# BearUongMilo

**[Tải phiên bản 2.0.1 cho Windows](https://github.com/BearUongMilo/BearUongMilo-Update/releases/tag/v2.0.1)**

## Cài đặt

1. Tải file `BearUongMilo_v2.0.1.zip` tại liên kết trên.
2. Giải nén toàn bộ vào một thư mục riêng.
3. Mở `BearUongMilo.exe` để sử dụng.

Giữ nguyên các tệp và thư mục sau khi giải nén. Không chạy ứng dụng trực tiếp
trong file ZIP và không di chuyển riêng file EXE.

Yêu cầu: Windows 10/11 64-bit và Microsoft Edge WebView2 Runtime.

## Kích hoạt bản quyền

Nhập key tại màn hình kích hoạt, chọn **Xác thực key**, sau đó bấm
**Mở ứng dụng**. Nếu key đã được lưu và còn hợp lệ, chỉ cần bấm **Mở ứng dụng**.

## Kết nối giả lập

1. Mở các giả lập MuMu cần sử dụng.
2. Vào **Cài đặt → Giả lập**, chọn đường dẫn `MuMuManager.exe` và lưu cài đặt.
3. Mở **Tổng quan (Dashboard) → Kết nối giả lập**.
4. Nhập tiền tố tên giả lập, ví dụ `BL`, rồi bấm **Tìm giả lập**. Để trống nếu
   muốn tìm tất cả giả lập đang mở.
5. Chọn các giả lập cần dùng và bấm **Gán Device ID**.

## Chạy workflow

1. Vào **Trình dựng workflow (Workflow Studio)** để tạo hoặc mở workflow đã có.
2. Kiểm tra cấu hình các node và dây nối.
3. Bấm **Chạy workflow**, chọn giả lập rồi xác nhận chạy.

Theo dõi tiến độ ở **Tổng quan**, xem màn hình và nhật ký xử lý tại
**Gỡ lỗi workflow (Debug Workflow)**. Các kết quả đã lưu nằm trong **Kết quả**.

## Cập nhật phiên bản

- Nếu đang dùng phiên bản cũ, bấm **Kiểm tra cập nhật** trong ứng dụng và làm
  theo hướng dẫn để nâng cấp lên 2.0.1.
- Với phiên bản 2.0.1, hãy theo dõi [trang phát hành](https://github.com/BearUongMilo/BearUongMilo-Update/releases)
  để tải bản mới. Phiên bản này chưa hỗ trợ tải và cài cập nhật trực tiếp trong ứng dụng.

## Khi cần hỗ trợ

Gửi kèm số phiên bản, ảnh thông báo lỗi và các bước đã thực hiện để việc kiểm
tra được nhanh và chính xác hơn. Không chia sẻ key hoặc mật khẩu trong ảnh gửi hỗ trợ.
